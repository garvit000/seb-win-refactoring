SEB Development Launch Test Page

Stands in for the "Open in Safe Exam Browser" button on an assessment site, so the click-to-launch flow can be tested against your local Windows development build.

Open in Safe Exam Browser (Dev)
This button links to sebdevs://safeexambrowser.org/start
This is not the production link. A real assessment site uses seb:// or sebs://, which Windows routes to the installed production Safe Exam Browser. This page uses sebdev:// / sebdevs://, registered in your user account to launch the local development build. Real exam links remain completely unaffected.
SchemeOpened byConfiguration
seb://
sebs://		 Installed Safe Exam Browser The assessment's own .seb (full exam lockdown)
sebdev://
sebdevs://		 Development Handler → run-dev.ps1 SEBDevelopment.seb (windowed, app switching enabled)
If clicking the button does nothing:
  1. Run .\register-url-handler.ps1 in PowerShell — the protocol handler must be registered.
  2. Run .\check-last-run.ps1 — it verifies each step in the launch chain.
  3. Check build\url-handler.log — if empty, the browser click did not trigger the handler.
